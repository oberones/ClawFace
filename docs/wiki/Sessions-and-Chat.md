# Sessions and Chat

The chat surface is the center of ClawFace. Sessions are treated as real working
contexts rather than disposable tabs.

## Sessions Sidebar

The Sessions sidebar shows available OpenClaw sessions with:

- session name
- preview text
- updated time
- activity indicators
- current-session marker
- rename and delete actions

Use search to find sessions by visible metadata and loaded preview content.

## Creating Sessions

Use **New Session** to create a new chat session. ClawFace can use your new
session defaults from Settings when starting a session.

## Renaming Sessions

Use the rename action on a session card to set a ClawFace display name for that
OpenClaw session.

This is useful when imported sessions have awkward names or when the name chosen
during creation does not stick. ClawFace keeps a local mapping between the
display name and the underlying OpenClaw session identity.

## Deleting Sessions

Use the delete action on a session card to remove a session. Follow any
confirmation prompts carefully.

## Chat Header Controls

The chat header separates:

- model and thinking state
- OpenClaw surfaces such as Dreams
- appearance mode
- new-session action
- Settings

## Tool Activity

When enabled, tool activity appears in the conversation flow so you can see what
OpenClaw is doing without digging through raw traces.

## Attachments

ClawFace supports desktop attachment workflows:

- drag and drop files
- paste images
- stage attachments before sending
- reuse compatible media from the Media view
- preview images in chat
- right-click images in the preview window to use native image actions such as
  Save As
