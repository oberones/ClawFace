# Interface Customization

ClawFace includes desktop-oriented customization for long working sessions.

## Appearance

Settings include:

- light and dark mode
- color system controls
- markdown readability controls
- panel opacity
- background pattern strength

## Typography And Layout

Settings include:

- font family
- font size
- line height
- content width
- sidebar width
- memory/Dreams panel width
- sidebar font size
- message gap
- chat bubble radius

The Sessions, Chat, and Dreams panes can also be resized directly by dragging
their vertical seams on desktop/tablet layouts.

## Avatar Styles

ClawFace includes selectable pixel-art avatar styles. Avatar animation states
include:

- idle
- thinking
- streaming
- tool-running
- success
- serious
- caution
- warning
- approval-needed
- disconnected

Reduced-motion and animation settings are respected by the avatar surface.

## Sounds

Reply-complete sounds can be enabled, disabled, adjusted, or replaced with a
custom audio source from Settings.

## Shortcuts And Schemes

Settings can store:

- app action shortcuts
- model shortcut schemes
- agent/session shortcut schemes
- reusable settings schemes
